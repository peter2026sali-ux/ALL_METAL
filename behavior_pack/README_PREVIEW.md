# Preview Screenshot Guide

To quickly spawn a screenshot-ready demo scene inside Minecraft Bedrock using the ALL_METAL add-on, do the following after importing the mcaddon:

1. Create a new world and enable Experimental Gameplay (and Enable Scripting/GameTest if available).
2. Add the ALL_METAL behavior and resource packs to the world and make sure they're active.
3. In Creative mode, open the inventory and find the item "Preview Wand" (search for "preview_wand" or look under Tools).
4. Equip the Preview Wand and right-click/use it (use button) in the world. The pack's script will spawn a small demo platform to your right and give you sample Copper items (magnet, bucket, toolbox).
5. Arrange the camera and take screenshots:
   - Windows 10/11: press F2 or use the Xbox Game Bar (Win+G) to capture.
   - Android/iOS: use system screenshot (Power+Volume or gestures).
6. If you want multiple scenes, move a little and use the wand again.

Note: If the Preview Wand does not appear or scripts don't run, check that Experimental Gameplay and Scripting are enabled.
