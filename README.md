# ALL METAL — Ultimate Utility (Minecraft Bedrock 1.26.45)

This repository contains the source for the ALL METAL Add-On (full version with experimental scripting).

Contents
- behavior_pack/: behavior definitions, scripts, recipes (Copper sample included)
- resource_pack/: models, textures and render/animation controllers (Copper sample included)

Quick start (Copper sample)
1. Download the `ALL_METAL_COPPER_SAMPLE.mcaddon` from Releases (or import the BP+RP manually).
2. In Minecraft Bedrock (v1.26.45), create a new world and enable: `Experimental Gameplay` and `Enable Scripting` if required.
3. Import the mcaddon or copy the `behavior_pack` and `resource_pack` folders into `%appdata%\Local\Packages...\minecraftpe\LocalState\games\com.mojang\` `behavior_packs` and `resource_packs`.
4. Add the packs to the world and test the Copper items: Copper Bucket, Copper Chest, Copper Magnet, Copper Hopper sample.

Notes
- This initial commit is a functional Copper-tier sample (textures are stylized metallic placeholders). Full tiers (Iron/Gold/Diamond/Netherite) will be added after Copper approval.
- The full add-on requires Experimental Gameplay to be enabled for scripting features.
